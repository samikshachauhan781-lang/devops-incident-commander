**Investigation:** The reported "blank screen" issue on `/incidents` route.

**Findings:**
1. **IncidentList.tsx** component has proper loading/error/empty states
2. **IncidentContext** correctly calls `incidentService.getIncidents()` on mount

**Root Cause Hypothesis:** The blank screen would occur if:
- Backend not running on port 8000
- Proxy not configured in production (but it is in vite preview)
- CORS blocking requests (but demo mode sets `DEMO_FRONTEND_ORIGIN`)

**Verification Status:** **UNVERIFIED** - Cannot confirm fix without manual browser test. The build succeeds and all API tests pass, but the blank-screen issue is a runtime integration problem requiring browser verification.
